# 결정 012: 마케팅 적합도 점수와 운영 학습 루프

- 상태: 채택
- 날짜: 2026-08-02

## 배경

기존 실행은 후보 46명 중 추천 0명, 보류 6명, 제외 40명이었습니다. 최근 활동, 영상 수, 조회수, 바이럴 편중과 카테고리 불확실성이 연속 하드 게이트처럼 작동했고 한 검색어와 60초 실행 한도 안에서 추천 목표 50명을 요청했습니다. 개별 조건 하나가 부족해도 다른 마케팅 강점으로 보완할 수 없었고, 동적 신호가 바뀌어도 과거 판정을 다시 확인할 경로가 없었습니다.

## 결정

최종 판정 세 값과 비협상 하드 제외를 유지하면서 100점 마케팅 적합도 모델을 도입합니다. 배점은 카테고리 25, 한국 시장 20, 활동성 20, 도달력 20, 진정성 10, 연락 가능성 5입니다. 기본 추천 기준은 70점, 보류 하한은 50점입니다.

최근 활동, 최근 영상 수, 조회수, 바이럴 편중, 구독자 목표 범위와 미확인 카테고리는 하드 제외가 아닙니다. 추천은 하드 제외 없음, 70점 이상, 확인된 개인 연락처와 필수 근거 충족으로 결정합니다. 점수 50~69, 고득점이지만 연락처 또는 필수 근거 미확인은 보류합니다. 충분한 근거가 있는 50점 미만만 동적 제외할 수 있습니다.

결과와 히스토리에 점수 구성요소, 연락 준비, 규칙 버전, 재검증 시각과 적용 설정을 저장합니다. 보류는 기본 21일, 동적 제외는 기본 45일 뒤 재검증하며 규칙 버전 변경도 동적 판정 재평가 사유입니다. 저장 실행 재평가는 새 YouTube 호출 없이 기존 근거를 현재 규칙으로 재생합니다.

자동 발견은 채널 검색과 날짜 제한 최근 영상 검색을 번갈아 사용하고 검색어당 10명 뒤 순환합니다. 20명 평가 뒤 추천이 없으면 검색 범위를 넓힙니다. 기본 동기 목표는 5명이며 20명 이상 목표는 백그라운드에서 실행합니다.

수동 판정은 자동 판정보다 우선하고 감사 이력을 남깁니다. 단, 조직 이메일과 다른 비협상 하드 제외를 올리거나 확인된 개인 연락처 없이 추천할 수 없습니다. 마케팅 승인부터 계약·콘텐츠 성과까지 후속 이벤트를 저장하되 성과가 규칙을 자동 변경하지는 않습니다.

## 검증 결과

동일한 저장 근거 46건을 새 규칙으로 재평가한 결과는 추천 7명, 보류 30명, 제외 9명이었습니다. 정적 적격 37명, 70점 이상 19명, 개인 연락 준비 16명이었고 70점 이상이면서 연락 준비된 10명 중 필수 근거가 미확인인 3명은 보류되었습니다. 조직 이메일 후보 2명은 모두 제외를 유지했습니다. 참고 목표 수를 맞추기 위한 예외나 표본 전용 하드코딩은 추가하지 않았습니다.

## 결과

- 동적 성과 신호 하나만으로 영구 제외되지 않습니다.
- 점수가 높은 보류가 검토 우선순위를 제공합니다.
- 규칙 변경과 TTL에 따라 동적 후보를 다시 확인할 수 있습니다.
- 실행 설정·퍼널·검색 순서와 수동 판정·후속 성과를 함께 분석할 수 있습니다.
- 판정 상태, 공식 API 전용 원칙, 조직 이메일 제외와 3필드 내보내기 계약은 유지됩니다.
