# 결정 011: 공식 YouTube Data API v3 전용 수집

- 상태: 채택
- 날짜: 2026-07-29

## 결정

운영 YouTube 수집에서 `youtubei.js`와 InnerTube 어댑터를 제거하고 공식 YouTube Data API v3만 사용합니다. 공식 API 키는 커밋되지 않는 서버 환경에만 저장하고 로그·오류·클라이언트 코드에 노출하지 않습니다.

최근 지표는 최신 업로드 최대 50개를 조회한 뒤 사용자가 지정한 최근 업로드 허용 기간으로 필터링합니다. 기간 내 최근 영상 수와 최신 10개까지의 평균 조회수를 판정 근거로 사용합니다. 불완전한 응답은 숫자 0으로 변환하지 않습니다.

공개 리크루팅 근거도 공식 API의 채널 설명과 최근 영상 제목·설명으로 수집합니다. 채널 설명에 직접 공개된 URL만 공식 사이트 후보로 사용할 수 있습니다.

## 결과

- 공식 API 키와 할당량이 라이브 실행의 필수 운영 의존성이 됩니다.
- `search.list` 비용을 고려해 기존 쿼리·페이지 안전 상한과 1분 실행 상한을 유지합니다.
- 과거 YouTube.js 오판 기록의 dry-run 복구 도구는 역사적 유지보수 용도로만 남습니다.
