# 001. 세 판정 모델

- **상태:** 채택
- **맥락:** 중복, 누락 근거와 검토 단계를 별도 판정 상태로 표현하면 사용자 결과 모델과 규칙이 복잡해집니다.
- **결정:** 크리에이터 판정은 `recommended`, `hold`, `excluded`만 사용합니다. 나머지 조건은 사유·경고·근거 필드로 표현합니다.
- **결과:** UI, 엔진, 그룹화와 테스트가 세 값에 의존합니다. 새 판정 값은 호환 변경이 아닙니다.
- **재검토 조건:** 제품이 세 값으로 표현할 수 없는 명확한 사용자 의사결정 흐름을 승인할 때만 재검토합니다.
