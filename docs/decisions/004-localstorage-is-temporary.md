# 004. localStorage는 임시 저장소

- **상태:** H2에서 대체됨
- **맥락:** 2단계에는 프로덕션 데이터베이스가 허용되지 않았지만 자동 히스토리 흐름을 검증할 저장소가 필요했습니다.
- **결정:** `BrowserHistoryRepository`의 `localStorage`는 목 단계 임시 구현이며 장기 원본이 아닙니다.
- **결과:** 기록은 브라우저·기기에 종속되고 서버 작업이나 협업에 사용할 수 없습니다.
- **재검토 조건:** H2에서 SQLite가 원본이 되었고 `localStorage`는 이전 목 버전의 브라우저 상태를 자동 전환하는 보조 수단으로만 남았습니다. 사용자 히스토리 입력이나 장기 원본으로 사용하지 않습니다.
