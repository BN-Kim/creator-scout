# 008 — H5.1 라이브 리크루팅 출처 승인 필요

## 상태

제품 결정 필요 — 2026-07-22

## 확인된 사실

저장소의 제품 규칙, 아키텍처, 공급자 문서, 개발 계획, 현재 상태와 기존 결정 기록을 감사한 결과 실제 연락·소속·국내 적합성 근거를 수집하도록 승인된 라이브 출처와 수집 방식은 없습니다.

H5 도메인의 `youtube_channel_about`, `creator_official_website`, `creator_public_profile`은 허구 픽스처를 정규화하기 위한 출처 유형입니다. 이 값은 YouTube 페이지 수집, 임의 웹사이트 탐색, 프로필 크롤링 또는 제3자 API 사용을 승인하지 않습니다. H3에서 승인된 YouTube 공급자는 채널 신원·공개 채널 통계·최근 영상 근거 범위에 한정되며 리크루팅 연락처 수집 승인이 아닙니다.

## 현재 결정

구체적인 제품 승인이 채택될 때까지 라이브 리크루팅 클라이언트를 구현하거나 연결하지 않습니다. 웹사이트, 스크래핑 서비스, 데이터 브로커, 검색 API 또는 제3자 연락처 API를 임의로 선택하지 않습니다. 로그인, 쿠키, CAPTCHA, 접근 제어, 비공개·숨김 정보 또는 의도적으로 공개되지 않은 연락 정보를 사용하는 방식은 승인 대상이 될 수 없습니다.

## 필요한 제품 결정

향후 승인 기록은 최소한 다음을 명시해야 합니다.

- 정확한 출처 운영자와 제품·페이지·API 명칭
- 허용되는 URL 또는 API 엔드포인트 범위
- 수집 방식과 인증 필요 여부
- 수집 가능한 연락·소속·시청자·국내 활동 필드
- 정보가 모집 연락 목적으로 공개되었다고 판단하는 기준
- 허용되는 요청 빈도, 보존 기간과 삭제 기준
- 접근 제한·로그인·CAPTCHA·비공개 정보가 나타날 때 즉시 중단하는 조건
- 출처별 원본 보존 범위와 비밀정보 제거 기준
- 네트워크 없이 사용할 허구 픽스처와 목 경계

## 결과

H5.1은 제품 결정 체크포인트에서 중단됩니다. 승인된 라이브 출처 유형이 0개이므로 라이브 클라이언트, 환경 설정, 의존성 또는 출처별 테스트를 추가하지 않습니다. 기존 H5 계약·정규화·출처 추적·불확실성·하드 게이트와 H4 히스토리 선검사·후보별 실패 격리는 그대로 유지합니다.

H6는 이 결정이 채택되기 전까지 시작하지 않습니다.
