# 008 — H5.1 라이브 리크루팅 출처와 수집 방식

## 상태

채택 — 2026-07-22

## 결정 배경

최초 저장소 감사에서는 실제 연락·소속·국내 적합성 근거를 수집하도록 승인된 라이브 출처와 수집 방식이 없었습니다. 제품 승인을 거쳐 아래의 제한된 공개 출처와 수집 방식만 H5.1 범위로 채택합니다.

H5 도메인의 출처 유형 자체는 범위 확대 승인이 아닙니다. 아래 목록에 없는 YouTube 화면, 임의 웹사이트 탐색, 일반 검색, 프로필 크롤링 또는 제3자 API 사용은 승인하지 않습니다.

## 승인된 출처와 방식

- 비인증 `youtubei.js` 세션으로 읽은 정확한 YouTube 채널의 공개 채널 설명과 직접 공개된 외부 링크
- 같은 채널의 최근 공개 영상 최대 20개의 제목과 설명
- 정확한 채널이 직접 링크한 공식 사이트의 공개 HTML
- 그 공식 사이트의 동일 등록 가능 도메인 안에서 실제 링크된 `contact`, `about`, `business`, `team`, `profile`, `roster` 성격의 공개 HTML 페이지

YouTube의 게이트된 “이메일 주소 보기”, 로그인·쿠키·CAPTCHA·접근 제어 우회, 일반 검색, URL 경로 추측, 제3자 주장, 데이터 브로커와 비공개·숨김 정보는 승인하지 않습니다. 공식 사이트는 `robots.txt`를 준수하고, 동일 등록 가능 도메인 밖 리디렉션은 중단합니다. HTML은 `cheerio`, 도메인 정규화는 `tldts`, robots 정책은 `robots-parser`, 동시성 제한은 `p-limit`을 사용합니다.

수집 필드는 화면에 명시적으로 게시된 이메일과 주변 문맥, 명시적 소속 문구, 공개 국가·언어 메타데이터, 채널 제목·설명, 최근 영상 제목·설명으로 제한합니다. 원문 HTML과 완전한 공급자 응답은 저장하지 않습니다.

한국어 활동 근거는 제목 한글 포함 비율, 한글 문자 비율과 명시적 한국 국가·활동 위치 근거를 별도로 기록하고 `likely`, `unclear`, `unlikely`로만 요약합니다. 이는 시청자 지역 근거가 아니며 승인된 일차 출처가 직접 제공하지 않는 한 시청자 지역은 미확인으로 유지합니다.

## 결과

라이브 수집은 기존 H4 히스토리 선검사를 통과한 신규 신원에만 적용합니다. 기존 H5 계약·정규화·출처 추적·불확실성·조직 하드 게이트, 후보별 실패 격리, 자동 저장과 멱등성을 재사용합니다. 제한 시간·페이지·리디렉션·응답 크기·호스트 요청률을 설정으로 제한하고 모든 자동 테스트는 허구 응답과 목 네트워크 경계만 사용합니다.
