# YouTube 신원 및 근거 공급자

YouTube 수집은 공식 YouTube Data API v3만 사용합니다. 후보 발견, 안정적 신원 확인, 채널 근거, 최근 영상 근거와 공개 설명 기반 리크루팅 근거는 기존 H3/H4/H5 계약 뒤에서 동작합니다. UI와 판정 엔진은 Google API 원시 응답에 직접 의존하지 않습니다.

## 필수 설정

- `YOUTUBE_API_KEY` — 필수. 실제 값은 커밋되지 않는 `.env.local`에만 둡니다.
- `YOUTUBE_REQUEST_TIMEOUT_MS` — 선택, 기본 10초
- `YOUTUBE_MAX_RETRIES` — 선택, 기본 2회, 최대 5회
- `YOUTUBE_RATE_LIMIT_MAX_RETRIES` — 선택, 검색 속도 제한 전용 기본 5회, 최대 8회
- `YOUTUBE_RATE_LIMIT_RETRY_BASE_DELAY_MS` — 선택, 검색 속도 제한 전용 지수 지연 기본 5초

API 키에는 YouTube Data API v3만 허용하고 가능한 경우 서버 IP 제한을 적용합니다. 키, 요청 URL과 쿼리 매개변수는 로그나 오류에 기록하지 않습니다.

## 공식 API 수집 흐름

1. `search.list(type=channel)`과 `search.list(type=video, order=date, publishedAfter=...)`를 번갈아 사용합니다.
2. 최근 영상 검색 결과의 `snippet.channelId`를 추출하고 채널 검색 결과와 합쳐 중복 제거합니다.
3. `channels.list`로 정확한 채널 ID, 채널명, 핸들, 통계와 업로드 재생목록을 확인합니다.
4. 안정적 채널 ID로 SQLite 히스토리와 동일 실행 중복을 먼저 검사합니다.
5. 신규 또는 재검증 대상 채널만 `playlistItems.list`로 최신 업로드를 최대 50개 확인합니다.
6. `videos.list`로 게시 시각, 조회수와 지속시간을 조회합니다.
7. 사용자가 지정한 활동 기간 안의 영상만 최근 지표에 포함합니다.
8. 판정과 저장이 끝난 결과만 실행 결과에 포함합니다.

`search.list`는 비용이 높은 일일 검색 할당량을 사용하므로 쿼리·페이지 안전 상한을 유지합니다. 한 번의 요청에서 최대 50개 후보를 받아 호출 수를 줄이고, 검색어당 최대 10명씩 순환하며 추천 목표에 도달하면 나머지 평가를 중단합니다. 19명 이하 목표는 기본 1분 동기 실행, 20명 이상은 기본 15분 백그라운드 실행입니다. `discover_candidates`의 HTTP 429 `rateLimitExceeded`는 일일 검색 할당량 소진으로 분류하여 다른 검색어를 연속 호출하지 않고 `provider_failure_limit_reached` 부분 결과로 중단합니다. 다른 작업의 일반 속도 제한은 더 긴 지수 지연과 `Retry-After` 값으로 같은 요청을 제한 재시도합니다.

## 최근 영상 지표 정의

- 수집 상한: 업로드 재생목록의 최신 50개
- 기간 기준: 실행 검증 시각에서 `maximumDaysSinceLatestUpload`일 전까지
- 최근 영상 수: 수집된 영상 중 기간 안에 게시된 영상의 수
- 최근 평균 조회수: 기간 안의 영상 중 최신 10개까지의 조회수 산술평균
- 최근 절사 평균: 표본이 충분하면 최댓값과 최솟값을 제외한 평균
- 최근 중앙값: 기간 안 조회수 표본의 중앙값
- 조회수/구독자 효율: 최근 중앙값을 구독자 수로 나눈 비율
- 최근 업로드일: 조회한 최신 업로드의 실제 게시 시각

삭제·비공개 영상, 누락된 게시 시각 또는 불완전한 영상 응답이 있으면 최근 영상 수와 조회 지표를 0으로 만들지 않고 미확인으로 유지합니다. 확정적으로 기간 안의 영상이 없을 때만 최근 영상 수 0이 될 수 있습니다. Shorts와 롱폼의 지속시간 표본은 따로 보존하지만 현재 점수는 형식별 조회 기준을 분리하지 않습니다.

## 공개 리크루팅 근거

공식 API의 채널 설명과 최근 영상 최대 20개의 제목·설명을 사용합니다. 채널 설명에 직접 공개된 HTTP(S) 링크만 해당 채널의 공식 사이트 후보로 전달합니다. Data API가 제공하지 않는 채널 배너 링크, 게이트된 이메일 버튼, 비공개 정보는 수집하지 않습니다.

## 테스트

모든 자동 테스트는 허구 채널 ID와 목 HTTP 응답만 사용합니다. 실제 API 키나 실시간 YouTube 접근은 필요하지 않습니다. 테스트는 공식 공급자 키 조건, 신원 정규화, 채널·최근 영상 혼합 발견, RFC 3339 날짜 필터, 채널 중복 제거, 최근 영상 수와 조회 지표, 불완전 응답의 미확인 처리, 리크루팅 설명 수집, 할당량·타임아웃·오류 비노출을 검증합니다.
