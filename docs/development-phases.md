# 개발 단계

## 1단계 — 인터페이스 MVP (완료)

주요 화면, 폼, 필터, 정렬과 목 데이터 구조를 검증했습니다.

## 2단계 — 결정론적 규칙과 로컬 히스토리 (현재)

세 판정 모델, 근거 기반 규칙 엔진, 신원 중복 매칭, 동일 실행 차단, 자동 로컬 히스토리, 수동 교정을 구현했습니다. 24개 허구 시나리오로 동작을 검증합니다.

## 3단계 — 승인된 영속성과 운영 안전성 (예정)

프로덕션 저장소, 스키마 마이그레이션, 사용자 권한과 감사 로그를 설계합니다. 현재 지시 범위에는 포함되지 않습니다.

## 4단계 — 승인된 데이터 연동 (예정)

별도 명시적 지시 후 공식 데이터 소스 어댑터와 할당량·재시도·원본 근거 보존을 추가합니다.
