## 현재 제한사항

- 히스토리는 서버의 로컬 SQLite 파일에 저장되며 여러 서버 인스턴스 사이에 자동 복제되지 않습니다.
- 목 근거는 실제 크리에이터 증거가 아닙니다.
- 규칙 엔진은 공급된 입력 데이터만 평가합니다.
- 최근 조회 평가기는 공급된 조회수 배열이 이미 비교 가능한 동일 형식 표본이라고 가정하며, 영상별 Shorts·롱폼 형식을 자동 분할하지 않습니다.
- 기존 2단계 목 실행은 회귀 하네스로 남아 있으며, H4 자동 실행은 과거·동일 실행 중복을 새 판정으로 표시하지 않고 조용히 건너뜁니다.
- 확정 판정과 히스토리는 SQLite에 지속되지만 현재 실행 결과 묶음은 서버 프로세스 메모리에만 유지되어 서버 재시작 후 상세 화면을 다시 열 수 없습니다.
- 기본 `innertube` 자동 실행은 API 키가 필요하지 않습니다. `official`을 선택할 때만 `YOUTUBE_API_KEY`가 필요하며, 모든 자동 테스트는 실제 키나 네트워크 없이 허구 목 공급자만 사용합니다.
- InnerTube는 공개된 내부 인터페이스를 사용하므로 YouTube 응답 구조 변경, 접근 제한 또는 공급자 비호환 오류가 발생할 수 있습니다. 쿠키·계정 인증·CAPTCHA 우회·프록시·지문 회피는 사용하지 않습니다.
- H5.1은 공개적으로 보이는 값만 수집합니다. 게이트된 YouTube 이메일 버튼, 로그인·CAPTCHA·쿠키·프록시·지문 회피·URL 추측·제3자 주장·비공개 정보는 사용하지 않습니다.
- 한국어 활동 상태는 언어·활동 신호일 뿐 시청자 지역 검증이 아닙니다. 승인된 일차 출처가 직접 제공하기 전까지 시청자 지역은 미확인입니다.
- YouTube Data API는 Shorts 노출 여부를 직접 제공하지 않으므로 H3는 제공된 지속시간으로 Shorts 길이·롱폼 길이 표본만 파생합니다.

H4.2는 자동 실행의 수량 의미를 최초 후보 수에서 신규 추천 목표 수로 바로잡았습니다. H5.1은 결정 008의 제한된 공개 출처를 기존 H5 정규화와 H4 신규 신원 경계에 연결했습니다. 확인된 조직 연락처와 소속은 기존 하드 게이트를 사용하며 판정 상태·규칙·임계값·3필드 내보내기 계약은 변경하지 않았습니다. 모든 자동 테스트는 허구 픽스처와 목 네트워크 경계만 사용합니다. 현재 안전 기준선과 명령은 [`verification.md`](verification.md)에 기록하며 다음 승인 작업은 [`next-task.md`](next-task.md)의 H6입니다.
