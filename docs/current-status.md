## 현재 제한사항

- 히스토리는 서버의 로컬 SQLite 파일에 저장되며 여러 서버 인스턴스 사이에 자동 복제되지 않습니다.
- 목 근거는 실제 크리에이터 증거가 아닙니다.
- 서버 측 자동 스카우팅을 실행할 수 없습니다.
- 규칙 엔진은 공급된 입력 데이터만 평가합니다.
- 최근 조회 평가기는 공급된 조회수 배열이 이미 비교 가능한 동일 형식 표본이라고 가정하며, 영상별 Shorts·롱폼 형식을 자동 분할하지 않습니다.
- 실제 과거 크리에이터 목록은 가져오지 않았습니다.

H2는 SQLite 스키마, 마이그레이션, 서버 저장소, 브라우저 원본 전환, 필드 보존과 반복·경합 쓰기 중복 방지를 구현해 완료했습니다. Playwright는 별도 브라우저 컨텍스트에서도 같은 서버 히스토리를 조회함을 검증합니다. 현재 안전 기준선과 명령은 [`verification.md`](verification.md)에 기록합니다. 다음 승인 단계는 [`next-task.md`](next-task.md)의 H3 레거시 히스토리 마이그레이션입니다.
