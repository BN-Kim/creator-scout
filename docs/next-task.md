# 다음 작업: H5.1 라이브 리크루팅 출처 제품 결정

H5.1 저장소 문서 감사를 완료했으며 현재 명시적으로 승인된 라이브 리크루팅 출처와 수집 방식은 없습니다. 따라서 라이브 클라이언트 구현은 중단되어 있습니다. H6를 시작하기 전에 이 제품 결정을 완료해야 합니다.

## 현재 승인 상태

- 승인된 라이브 출처: 없음
- 승인된 라이브 수집 방식: 없음
- 구현 가능한 라이브 클라이언트: 없음

`youtube_channel_about`, `creator_official_website`, `creator_public_profile`은 H5 허구 픽스처의 정규화 출처 유형일 뿐 라이브 수집 승인이 아닙니다. YouTube Data API와 InnerTube의 기존 승인은 H3 채널·영상 근거 범위에만 적용됩니다.

## 필요한 제품 결정

제품 책임자는 [`decisions/008-live-recruitment-source-approval-required.md`](decisions/008-live-recruitment-source-approval-required.md)의 필수 항목을 충족하는 출처 승인안을 제공해야 합니다. 최소한 다음이 필요합니다.

- 정확한 출처 운영자와 제품·페이지·API 명칭
- 허용 URL 또는 API 범위와 수집 방식
- 모집 목적으로 의도적으로 공개된 정보의 판별 기준
- 허용 필드, 요청 빈도, 보존·삭제 기준
- 로그인·CAPTCHA·접근 제한·비공개 정보 발견 시 중단 조건
- 원본 보존과 비밀정보 제거 기준

## 승인 전 금지 사항

- 임의 웹사이트 또는 프로필 크롤링
- 스크래핑 서비스, 데이터 브로커, 검색 API 또는 연락처 API 선택
- 로그인, 쿠키, CAPTCHA 또는 접근 제어 우회
- 비공개·숨김 연락처 수집
- 이메일·소속·시청자·국내 적합성 추론
- 라이브 클라이언트, 환경변수 또는 의존성 추가
- H6 구현 시작

## 승인 후 구현 기준

승인된 출처가 생기면 해당 출처만 기존 H5 계약과 H4 파이프라인에 연결합니다. 히스토리 선검사 뒤 신규 신원에만 호출하고, 원본·정규화 분리, 출처 URL·관측 시각·확인 상태, 후보별 실패 격리, 세 판정·하드 게이트·임계값·SQLite·3필드 JSON 계약을 유지해야 합니다. 지원하는 각 출처 유형마다 허구 픽스처와 네트워크 없는 목 공급자 테스트를 추가합니다.

## 완료 명령

구현이 명시적으로 승인된 뒤 다음을 실행합니다.

```bash
npm run verify
npm run test:providers
npm run test:e2e
```

제품 결정 전에는 H5.1을 구현 완료로 표시하거나 `docs/next-task.md`를 H6로 전환하지 않습니다.
