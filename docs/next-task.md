# 다음 권장 작업: H1 UI 스모크 테스트

## 목표

현재 목 애플리케이션의 기존 동작을 실제 브라우저 수준에서 검증하는 자동 스모크 테스트를 추가합니다. 제품 기능이나 UI는 변경하지 않습니다.

## 테스트 경로

- `/`
- `/runs/new`
- `/runs/mock-new-run`
- `/history`
- `/settings`

## 검증 흐름

- 대시보드와 탐색 링크가 정상 렌더링된다.
- 새 추천 실행 폼의 무효 입력이 오류를 표시하고 유효 입력이 상세 화면으로 이동한다.
- 상세 화면에 추천, 보류, 제외가 각각 표시되고 한 크리에이터가 여러 그룹에 나타나지 않는다.
- 실행 완료 후 히스토리 기록이 브라우저 저장소에 반영된다.
- 수동 교정이 현재 결과를 제외로 바꾸고 히스토리를 갱신하며 한국어 확인 메시지를 표시한다.

## 완료 기준

- 테스트는 독립적인 브라우저 저장소 상태에서 반복 실행 가능하다.
- 필수 경로와 위 사용자 흐름을 자동 검증한다.
- 실패 시 어떤 경로 또는 동작이 깨졌는지 출력한다.
- 기존 단위·계약 테스트와 `npm run verify`가 계속 통과한다.
