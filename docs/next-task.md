# 다음 승인 단계: H6 예약과 운영

H0~H5와 YouTube.js 공급자 통합 작업은 완료되었습니다. 다음 단계는 자동 스카우팅 파이프라인을 안전하게 예약·관찰·제어하는 H6이며, 이 문서는 H6만 정의합니다. 별도 구현 지시 전에는 H6를 시작하지 않습니다.

## 목표

기존 H4/H5 파이프라인의 판정·중복·저장 계약을 변경하지 않고 예약 실행, 동시 실행 방지, 제한된 재시도, 운영 관찰과 복구 기능을 추가합니다.

## 범위

- 설정 가능한 예약 실행과 명시적 활성화·중지
- 동일 작업의 중복 실행을 막는 실행 잠금
- 기존 구조화 오류 분류에 따른 제한된 재시도와 백오프
- 공급자 속도 제한과 실행별 처리 한도
- 실행 상관관계 ID가 포함된 구조화 로그
- 실행·실패·재시도·중복 건너뛰기 운영 지표
- 중단된 실행의 안전한 복구와 운영 상태 조회
- 기존 자동 실행 파이프라인 재사용

## 비범위

- 새 판정 상태, 판정 규칙 또는 임계값
- 신규 데이터 공급자와 실제 운영 리크루팅 출처 연결
- AI 판정 또는 분석
- 인증·권한 시스템
- 히스토리 파일 가져오기
- 다중 리전 데이터 복제 또는 배포 인프라

## 완료 기준

- 같은 예약 작업은 동시에 두 번 실행되지 않는다.
- 운영자가 예약을 명시적으로 중지·재개하고 현재 상태를 확인할 수 있다.
- 재시도 가능 오류만 정해진 한도 안에서 재시도하며 영구 오류는 재시도하지 않는다.
- 속도 제한과 배치 한도가 공급자 호출을 제어한다.
- 로그와 지표에서 실행 ID, 단계, 결과, 실패와 중복 건너뛰기 수를 추적할 수 있다.
- 중단 후 복구가 확정 판정이나 히스토리 중복을 만들지 않는다.
- H4/H5의 히스토리 선검사, 신규 결과 전용 표시, 자동 저장과 멱등성이 유지된다.
- 세 판정 모델, 결정 엔진, SQLite와 3필드 JSON 계약이 유지된다.

## 필수 테스트

- 예약 활성화·중지·재개
- 동일 작업 실행 잠금과 경합
- 재시도 가능·영구 오류 및 재시도 한도
- 백오프와 공급자 속도 제한
- 실행 상관관계 로그와 운영 지표
- 중단 실행 복구와 반복 실행 멱등성
- H4/H5 중복 건너뛰기·자동 저장·부분 실패 회귀
- 기존 단위·공급자·저장소·계약·브라우저 회귀 테스트

## 완료 명령

```bash
npm run verify
npm run test:e2e
```

H6는 기존 자동 스카우팅 파이프라인을 운영 가능하게 만드는 단계이며 신규 판정 로직이나 데이터 획득 범위를 추가하지 않습니다.
