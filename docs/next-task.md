# 다음 작업: H7 운영 배포 의사결정 체크포인트

H6 예약과 운영이 완료되었습니다. 다음 승인 단계는 H7이며, 구현을 시작하기 전에 실제 운영 배포 경계를 문서로 확정하는 체크포인트입니다.

## 범위

- 실제 배포 대상과 장기 실행 프로세스 지원 여부
- 단일 인스턴스 또는 다중 인스턴스 요구
- SQLite 영속 볼륨, 백업 주기와 복구 목표
- 예약 실행을 담당할 프로세스 또는 플랫폼 요구
- 운영 화면 접근 제어 요구
- 환경 변수와 비밀 관리 방식 요구
- 승인된 결정에 근거한 다음 하나의 좁은 구현 단계 정의

## 비범위

- 실제 배포 또는 클라우드 자원 생성
- 외부 운영 데이터베이스, 큐, 분산 잠금 또는 클라우드 예약기 구현
- 인증·권한 체계 구현
- 신규 YouTube·리크루팅 공급자
- 판정 상태, 추천 규칙 또는 임계값 변경
- AI 판정이나 탐색

## 완료 기준

- 배포 플랫폼과 프로세스 수명주기가 명시적으로 승인됩니다.
- H6의 장기 실행 Node.js 프로세스와 공유 SQLite 전제가 유지 가능한지 기록됩니다.
- 데이터 보존, 백업과 장애 복구 목표가 정량적으로 기록됩니다.
- 운영 접근 제어와 비밀 관리 책임이 기록됩니다.
- 승인되지 않은 외부 인프라를 선택하거나 구현하지 않습니다.
- 후속 작업은 승인된 결정만 구현하는 하나의 좁은 단계로 작성됩니다.

## 필수 검증

- `docs/architecture.md`, `docs/current-status.md`, 결정 기록과의 교차 참조
- 현재 SQLite 마이그레이션·파일 경로·환경 변수·백업 경계 점검
- H6 스케줄러·잠금의 단일 서버 제약 확인
- 제품 규칙과 3필드 내보내기 계약 비변경 확인

## 완료 명령

```bash
npm run verify
npm run test:e2e
git diff --check
```

H7에서는 승인 없이 배포 기술이나 외부 서비스를 선택하지 않습니다. H7 후속 구현 단계는 이 체크포인트가 완료된 뒤에만 정의합니다.
