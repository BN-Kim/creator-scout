# 다음 작업: H6 예약과 운영

H5.1 공개 리크루팅 출처 연결, H4.2 추천 목표 충족 보정, 공급자 정확성 hotfix와 H4.3 자율 후보 발견·적응형 검색어 선택이 완료되었습니다. 다음 승인 단계는 H6이며, 이 문서는 H6 범위만 정의합니다.

## 범위

- 예약 실행
- 중복 실행을 막는 잠금
- 제한된 재시도와 속도 제한
- 구조화 로그와 실행 상관관계
- 모니터링 신호
- 실패 복구
- 운영 중지와 재개 제어

## 비범위

- 새 판정 상태
- 추천 규칙이나 임계값 변경
- 신규 데이터 공급자
- AI 판정
- 인증 또는 다중 사용자 권한 체계

## 완료 기준

- 예약 작업이 중복 실행 없이 관찰·제어됩니다.
- 재시도와 요청 속도가 명시된 상한을 지킵니다.
- 장애 후 복구가 기존 자동 저장과 멱등성을 보존합니다.
- 실행·오류·히스토리 중복 건너뛰기 통계를 상관관계 ID로 추적할 수 있습니다.
- 운영 중지와 재개가 새 판정 모델이나 기존 업무 규칙을 바꾸지 않습니다.

## 필수 테스트

- 예약
- 분산 잠금
- 재시도 한도
- 속도 제한
- 장애 복구
- 로그 상관관계
- 모니터링 신호
- 운영 중지와 재개

## 완료 명령

```bash
npm run verify
npm run test:e2e
```

H6 구현 전에는 구체적인 저장·실행 환경과 단일 서버 SQLite 제약을 검토해야 합니다. H6를 넘어서는 후속 단계는 시작하지 않습니다.
