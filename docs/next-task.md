# 다음 승인 단계: H5 리크루팅 근거 강화

H0~H4와 H4 이후의 YouTube.js 공급자 통합 작업은 완료되었습니다. 다음 단계는 H4 자동 실행에 리크루팅 판단에 필요한 확인 가능한 근거를 추가하는 H5이며, 이 문서는 H5만 정의합니다. 별도 구현 지시 전에는 H5를 시작하지 않습니다.

## 목표

명시적으로 승인된 출처에서 공개된 연락·소속·시청자 적합성 근거를 획득하고, 출처와 확인 상태를 보존한 채 기존 결정론적 판정 엔진에 공급합니다. 확인되지 않은 정보는 만들거나 추론하지 않습니다.

## 범위

- 승인된 공개 출처를 위한 공급자 계약
- 공개 연락 근거의 출처·확인 시각 보존
- 개인 소유 연락처와 회사·에이전시·매니지먼트·MCN·레이블 소유 연락처 분류
- 소속 유형 근거와 확인 상태
- 국내 시청자·국내 활동 적합성 근거와 불확실성
- 상충하거나 누락된 근거의 명시적 표현
- H4 `CreatorInput` 조합 경계에 추가 근거 연결
- 기존 조직 연락처 하드 게이트 회귀 보장

## 비범위

- 무단 이메일 스크래핑
- 비공개 연락처 획득
- 누락된 이메일·소속·시청자 정보 추론
- AI 기반 분류 또는 판정
- 판정 상태, 규칙 또는 임계값 변경
- 예약·백그라운드 실행과 H6 운영 제어
- 히스토리 파일 가져오기

## 완료 기준

- 모든 추가 근거는 출처, 확인 상태와 확인 시각을 가진다.
- 개인 연락처와 조직 소유 연락처가 명시적으로 구분된다.
- 회사·에이전시·매니지먼트·MCN·레이블 연락처는 기존 하드 게이트에 따라 일관되게 제외된다.
- 연락처나 소속을 확인할 수 없으면 값을 만들지 않고 미확인 상태를 유지한다.
- 국내 적합성 근거가 없거나 상충하면 확정 값으로 승격하지 않는다.
- 공급자 원본과 도메인 근거가 분리되고 출처를 추적할 수 있다.
- H4 중복 선검사·멱등 저장·신규 결과 전용 표시 계약이 유지된다.
- 기존 세 판정 모델, 규칙 엔진, SQLite와 3필드 JSON 계약이 유지된다.

## 필수 테스트

- 승인 출처 공급자 계약
- 개인·조직 연락처 분류
- 회사·에이전시·매니지먼트·MCN·레이블 소속 유형
- 국내 시청자·국내 활동 적합성 근거
- 미확인·누락·상충 근거 처리
- 원본·정규화 근거와 출처 보존
- 조직 소유 연락처 하드 게이트 회귀
- H4 중복 건너뛰기·멱등성·부분 실패 회귀
- 기존 단위·공급자·저장소·계약·브라우저 회귀 테스트

## 완료 명령

```bash
npm run verify
npm run test:e2e
```

H5는 승인된 출처와 증명 가능한 근거만 추가해야 하며, 연락처나 적합성을 추측하거나 새로운 판정 로직을 도입하지 않습니다.
