# 단계별 개발 계획

한 번에 한 단계만 진행합니다. 각 단계는 독립적으로 검증되고 완료 기준을 충족한 뒤 [`current-status.md`](current-status.md)를 갱신해야 합니다.

## H0 — 하네스 기준선 (완료)

- **범위:** 정식 문서 지도, 저장소 책임 지도, 통합 검증 명령, 계약 테스트, 골든 픽스처, 작업 템플릿.
- **비범위:** 제품 동작과 UI 변경, 외부 연동.
- **완료 기준:** 새 에이전트가 문서만으로 제품 규칙·구조·상태·다음 작업을 식별하고 검증 기준선을 재현한다.
- **필수 테스트:** 영구 판정·이메일·중복·히스토리·그룹화 계약.
- **완료 명령:** `npm run verify`.

## H1 — UI 스모크 테스트 (완료)

- **범위:** 브라우저 수준 경로, 폼 제출, 추천·보류·제외 표시, 히스토리 갱신, 수동 교정 테스트.
- **비범위:** UI 재설계, 실제 데이터, 새 제품 기능.
- **완료 기준:** 주요 사용자 흐름이 실제 브라우저에서 재현 가능하고 실패 시 명확한 테스트 출력을 제공한다.
- **필수 테스트:** 필수 경로 로드, 유효·무효 폼, 세 판정 그룹, 히스토리 저장, 수동 교정.
- **완료 명령:** `npm run verify`, `npm run test:e2e`.

## H2 — SQLite 서버 히스토리 (완료)

- **범위:** SQLite 선택, 스키마, `HistoryRepository` 서버 구현, `localStorage` 원본 역할 종료, 기존 목 브라우저 상태의 자동 전환.
- **비범위:** YouTube 연동, 사용자가 수행하는 히스토리 가져오기.
- **완료 기준:** 서버 저장소가 원본이고 브라우저 간 히스토리 일관성 및 저장 경계 중복 방지가 검증된다.
- **필수 테스트:** 저장소 계약, 스키마, 반복·경합 쓰기, 판정 매핑, 브라우저 간 일관성.
- **완료 명령:** `npm run verify`, `npm run test:e2e`.

## H3 — 실제 YouTube 신원 및 근거 공급자 (완료)

- **범위:** 후보 발견과 YouTube 근거 공급자 인터페이스, 안정적 채널 ID·핸들 정규화, 승인된 공급자를 통한 실제 채널·최근 영상 근거 조회, 원본 데이터와 파생 근거 구분, 공급 메타데이터가 충분할 때 Shorts·롱폼 표본 구분, 할당량·타임아웃·재시도·구조화 오류 처리, 비용이 큰 근거 수집 전 SQLite 히스토리 사전 확인과 과거 신원 건너뛰기.
- **비범위:** 완전 자동 다중 소스 탐색, 이메일 스크래핑, 예약 백그라운드 실행, AI 판정, 과거 파일 가져오기, H4 실행 오케스트레이션.
- **완료 기준:** 공급자 응답이 출처를 보존한 도메인 신원·근거로 정규화되고, 확정된 과거 신원은 근거 공급자를 호출하지 않은 채 건너뛰며, 실패 유형과 재시도 가능성이 구조화되어 반환된다.
- **필수 테스트:** 공급자 계약, 채널 ID·핸들 정규화, 검색·영상 URL 거부, 원본·파생 근거 분리, Shorts·롱폼 표본, 페이지네이션, 할당량·타임아웃·재시도·오류, 히스토리 사전 확인 시 공급자 미호출. 자동 테스트는 픽스처와 목 공급자 응답만 사용한다.
- **완료 명령:** `npm run verify`, `npm run test:e2e`.

## H4 — 자동 스카우팅 실행 파이프라인 (완료)

- **범위:** 설정 가능한 후보 배치 발견, 안정적 신원 정규화와 중복 제거, SQLite 히스토리 확인, 과거 채널 건너뛰기, 신규 채널 근거 수집, 기존 결정론적 엔진 호출, 모든 확정 판정 자동 저장, 신규 처리 결과만 표시, 발견·중복 건너뜀·평가·추천·보류·제외·실패 실행 통계, 반복 실행 멱등성.
- **비범위:** 연락처 근거 확장, 예약 실행, AI 판정, 히스토리 파일 관리.
- **완료 기준:** 각 신규 신원은 한 번만 평가·저장·표시되고 과거 신원은 비용이 큰 검증 전에 조용히 건너뛰며, 반복 실행이 추가 결과나 히스토리 중복을 만들지 않는다.
- **필수 테스트:** 단계별 파이프라인, 동일 실행 블록리스트, 과거 히스토리 사전 건너뛰기, 공급자 미호출, 자동 저장, 실행 통계, 부분 실패, 반복 실행 멱등성, 신규 결과 전용 표시.
- **완료 명령:** `npm run verify`, `npm run test:e2e`.

## H4.2 — 추천 목표 충족 보정 (완료)

- **범위:** 사용자 입력을 신규 추천 목표 수로 해석하고 목표가 충족될 때까지 페이지 단위 후보 발견과 기존 H4 평가를 계속한다. 과거·동일 실행 중복, 보류, 제외, 공급자·정규화·저장 실패는 목표를 충족하지 않으며, 보류와 제외는 정확히 한 번 저장한다. 후보·페이지·시간·공급자 실패 안전 상한과 구조화된 중단 사유를 제공한다.
- **비범위:** 판정 규칙·임계값 변경, H3/H5.1 공급자 교체, 예약 실행, H6 운영 기능.
- **완료 기준:** 추천 수가 요청 목표와 정확히 같을 때 즉시 종료하고 초과 추천을 만들지 않는다. 목표를 채우지 못하면 안전 상한 또는 소스 소진 사유와 충족 수를 반환하며 반복 실행은 멱등이다.
- **필수 테스트:** 중복·보류·제외·실패 뒤 목표 충족, 다중 페이지, 비용 큰 공급자 미호출, 보류·제외 저장, 실패 미저장, 초과 방지, 소스 소진, 네 안전 상한, 반복 실행 멱등성.
- **완료 명령:** `npm run verify`, `npm run test:providers`, `npm run test:e2e`, `git diff --check`.

## H4.3 — 자율 후보 발견과 적응형 검색어 선택 (완료)

- **범위:** 추천 목표만으로 시작하는 기본 자동 모드, `automatic`·`manual_replace`·`manual_extend` 발견 모드, 검증된 서버 발견 분류체계, 결정론적 한국어 검색어 생성, 쿼리·연속 페이지 상태의 SQLite 영속화, 최소 표본 기반 검색어 품질 점수, 카테고리·검색 범위 탐색 회전, 신규 추천 공개 메타데이터에서만 얻는 안전한 탐색 문구.
- **비범위:** 판정 규칙·임계값 변경, 외부 AI, 새 공급자, 예약 실행, H6 운영 기능.
- **완료 기준:** 검색어 없이 자동 실행할 수 있고 추천 목표 또는 기존 안전 상한까지 여러 검색어와 연속 페이지를 탐색한다. 쿼리 점수는 발견 우선순위만 바꾸며 판정에 관여하지 않는다. 진행 상태는 재시작 뒤 이어지고 중복은 비용이 큰 근거 수집 전에 제거된다.
- **필수 테스트:** 무검색어 자동 실행, 두 수동 모드, 결정론적 생성, 범위·카테고리 회전, 연속 페이지 영속화, 최소 표본 점수, 추천 전용 학습 문구, 냉각·폐기, 목표 충족, 중복 선검사, 안전 중단, 기존 H3~H5.1 회귀.
- **완료 명령:** `npm run verify`, `npm run test:providers`, `npm run test:e2e`, `git diff --check`.

- **비범위:** 무단 이메일 스크래핑, 누락 정보 추론, AI 판정, 예약 실행.
- **완료 기준:** 모든 추가 근거가 출처와 확인 상태를 가지며 조직 소유 연락처가 기존 하드 게이트로 일관되게 제외되고 미확인 정보는 만들어내지 않는다.
- **필수 테스트:** 승인 출처 어댑터, 개인·조직 분류, 소속 유형, 국내 적합성, 미확인·상충 근거, 출처 보존, 조직 이메일 하드 게이트 회귀.
- **완료 명령:** `npm run verify`, `npm run test:e2e`.

## H5.1 — 라이브 승인 출처 연결 (완료)

- **범위:** 저장소 문서에 명시적으로 승인된 라이브 리크루팅 출처와 수집 방식 확인, 승인된 출처가 있을 때만 기존 H5 계약 뒤에 서버 클라이언트 연결.
- **비범위:** 임의 웹사이트·스크래핑 서비스·데이터 브로커·제3자 API 선택, 로그인·CAPTCHA·접근 제어 우회, 비공개 정보, H6 운영 기능.
- **구현 결과:** 결정 008에서 승인한 정확한 YouTube 공개 설명·최근 영상 설명·채널 직접 링크 공식 사이트만 기존 H5/H4 경계에 연결했다. 접근 제한을 우회하지 않고 한국어 활동 근거를 시청자 지역과 분리한다.
- **완료 기준:** 승인 기록이 정확한 출처·수집 방식·허용 필드·중단 조건을 명시한 뒤, 해당 출처만 기존 H5/H4 경계에 연결하고 네트워크 없는 출처별 픽스처·목 테스트를 통과한다.
- **완료 명령:** 구현이 승인된 경우 `npm run verify`, `npm run test:providers`, `npm run test:e2e`.
