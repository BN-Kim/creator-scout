# 단계별 개발 계획

한 번에 한 단계만 진행합니다. 각 단계는 독립적으로 검증되고 완료 기준을 충족한 뒤 [`current-status.md`](current-status.md)를 갱신해야 합니다.

## H0 — 하네스 기준선 (완료)

- **범위:** 정식 문서 지도, 저장소 책임 지도, 통합 검증 명령, 계약 테스트, 골든 픽스처, 작업 템플릿.
- **비범위:** 제품 동작과 UI 변경, 외부 연동.
- **완료 기준:** 새 에이전트가 `AGENTS.md`와 문서만으로 제품 규칙·구조·상태·다음 작업을 식별하고 `npm run verify`로 기준선을 증명할 수 있다.
- **필수 테스트:** 영구 판정·이메일·중복·히스토리·그룹화 계약.
- **완료 명령:** `npm run verify`.

## H1 — UI 스모크 테스트 (완료)

- **범위:** 브라우저 수준 경로, 폼 제출, 추천·보류·제외 표시, 히스토리 갱신, 수동 교정 테스트.
- **비범위:** UI 재설계, 실제 데이터, 새 제품 기능.
- **완료 기준:** 주요 사용자 흐름이 실제 브라우저에서 재현 가능하고 실패 시 명확한 테스트 출력을 제공한다.
- **필수 테스트:** 필수 경로 로드, 유효·무효 폼, 세 판정 그룹, 히스토리 저장, 수동 교정.
- **완료 명령:** UI 스모크 명령과 `npm run verify`.

## H2 — 서버 영속 히스토리 (완료)

- **범위:** 데이터베이스 선택, 스키마, `HistoryRepository` 서버 구현, `localStorage` 원본 역할 종료, 마이그레이션 경로.
- **비범위:** YouTube 연동, 레거시 데이터 가져오기.
- **완료 기준:** 서버 저장소가 원본이고 브라우저 간 히스토리 일관성 및 중복 방지가 검증된다.
- **필수 테스트:** 저장소 계약, 스키마, 동시 중복 방지, 판정 매핑 호환성.
- **완료 명령:** 저장소 마이그레이션 검사와 `npm run verify`.

## H3 — 레거시 히스토리 마이그레이션

- **범위:** 연결된 JSON 배열 파서, URL 분류, 미해결 레코드 보존, 중복 조정, 일회성 가져오기 절차.
- **비범위:** 실시간 데이터 수집, 불확실 신원의 자동 병합.
- **완료 기준:** 입력 손실 없이 재실행 가능한 가져오기와 감사 가능한 결과 보고서가 생성된다.
- **필수 테스트:** 비정상 JSON 경계, URL 종류, 미해결 레코드, 중복, 멱등성.
- **완료 명령:** 마이그레이션 건식 실행과 `npm run verify`.

## H4 — YouTube 데이터 공급자 어댑터

- **범위:** 공급자 인터페이스, 공식 YouTube API 구현, 채널 신원·업로드·영상 조회, 할당량과 오류 처리.
- **비범위:** 검색 공급자 확대, 규칙 재설계.
- **완료 기준:** 고정 픽스처와 승인된 API 응답을 동일한 도메인 입력으로 변환한다.
- **필수 테스트:** 어댑터 계약, 신원 확인, 페이지네이션, 할당량·오류, 픽스처 재현.
- **완료 명령:** 어댑터 계약 테스트와 `npm run verify`.

## H5 — 실제 평가 파이프라인

- **범위:** 근거 수집, 기존 엔진 평가, 결과 저장, 중복 처리 방지, 실행 진행률 표시.
- **비범위:** 신규 탐색 소스와 예약 실행.
- **완료 기준:** 공급된 후보가 한 번만 처리되고 근거·판정·히스토리가 추적 가능하다.
- **필수 테스트:** 단계별 파이프라인, 실패 재개, 멱등성, 진행률, 저장 결과.
- **완료 명령:** 파이프라인 통합 테스트와 `npm run verify`.

## H6 — 탐색 어댑터

- **범위:** 키워드 탐색, 승인된 외부 탐색 소스, 출처 기록, 고비용 검증 전 중복 제거.
- **비범위:** 자동 예약과 운영 모니터링.
- **완료 기준:** 후보 출처가 보존되고 동일 신원이 검증 전에 중복 제거된다.
- **필수 테스트:** 탐색 어댑터 계약, 출처, 중복 제거, 오류 격리.
- **완료 명령:** 탐색 계약 테스트와 `npm run verify`.

## H7 — 예약과 운영

- **범위:** 백그라운드 작업, 재시도, 실행 잠금, 로그, 모니터링, 장애 복구.
- **비범위:** 새로운 판정 상태와 규칙 변경.
- **완료 기준:** 중복 실행 없이 실패를 관찰·재시도·복구할 수 있다.
- **필수 테스트:** 잠금, 재시도 한도, 장애 복구, 로그 상관관계, 모니터링 신호.
- **완료 명령:** 운영 시나리오 테스트와 `npm run verify`.
