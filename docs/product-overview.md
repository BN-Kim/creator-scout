# 제품 개요

크리에이터 스카우트는 확인된 신원과 검증 근거를 재현 가능한 규칙으로 평가하는 내부 운영 애플리케이션입니다.

## 2단계 목표

모든 후보를 추천, 보류, 제외 중 하나로 분류하고 결과와 사유를 자동 히스토리에 기록합니다. 중복은 별도 상태가 아니라 제외 판정과 사유 코드로 표현합니다. 수동 교정은 자동 판정을 덮어쓰고 같은 실행과 히스토리에 즉시 반영됩니다.

## 데이터 원칙

확인하지 않은 근거는 `false`가 아니라 명시적인 `null` 또는 `not_checked`로 유지합니다. 검색 결과나 영상 URL은 채널 신원으로 사용하지 않습니다. 현재 데이터는 모두 허구의 목 시나리오입니다.
