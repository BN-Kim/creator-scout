# 제품 개요

크리에이터 스카우트의 목표는 새로운 YouTube 채널을 자동 발견하고 안정적인 신원으로 정규화한 뒤, SQLite 히스토리의 과거 신원을 비용이 큰 검증 전에 건너뛰고, 진정으로 새로운 채널만 근거 수집·결정론적 판정·자동 저장하는 운영 애플리케이션입니다. 현재 실행 결과에는 새로 처리한 크리에이터만 포함하며 히스토리는 사용자가 관리하는 파일이 아니라 애플리케이션의 내부 기억입니다.

현재 구현과 미구현 범위는 [`current-status.md`](current-status.md), 정식 업무 규칙은 [`product-rules.md`](product-rules.md)를 참고하세요.
